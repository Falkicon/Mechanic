# Skill File Format

Structure and requirements of a `SKILL.md`.

## Structure

```markdown
---
name: skill-name
description: >
  What it does and covers. When to load it. Triggers: keyword, keyword.
---

# Title

Short intro, then capabilities, routing and core rules.
```

## Front matter

- `name` (required): lowercase letters, digits and hyphens, at most 64 characters, **identical to the directory name**.
- `description` (required): at most 1024 characters, trigger-oriented. It is always loaded, so say what the skill covers and when to use it, then list trigger keywords. Folded `>` YAML keeps it readable.

## Body

1. H1 title and one sentence of intent.
2. `## Related Commands` (s- skills): links to the `c-` commands.
3. `## MCP Tools`: a table of tool calls (names as registered, for example `addon.lint(addon="MyAddon")`). Do not list CLI commands for agents.
4. Capabilities or key concepts.
5. `## Routing Logic`: which reference to load for which request.
6. Core rules and a short quick reference.

Keep the body concise; it loads into context. Deep content belongs in `references/`.

## Location

```
.claude/skills/<skill-name>/SKILL.md      canonical
.agent/skills/<skill-name>/SKILL.md       generated by .claude/sync_ide.py (do not edit)
```

## Links

Links are relative to the file containing them:

| From | To | Link |
|------|----|------|
| `skills/<s>/SKILL.md` | repository docs | `../../../docs/integration/testing.md` |
| `skills/<s>/SKILL.md` | another skill | `../k-fenui/SKILL.md` |
| `skills/<s>/SKILL.md` | a command | `../../commands/c-lint.md` |
| `commands/c-x.md` | a skill | `../skills/s-x/SKILL.md` |
| `skills/<s>/references/x.md` | the skill itself / another skill | `../SKILL.md`, `../../k-x/SKILL.md` |

The `.agent` generator re-resolves these for the generated layout (commands become `workflows/<verb>.md`), so write them for `.claude` only. Do not write example links that point nowhere; put examples in code spans.

## Minimal example

```markdown
---
name: s-example
description: >
  Example skill showing the minimal structure. Use when demonstrating the format.
  Triggers: example, template.
---

# Example

Shows the minimal skill structure.

## Capabilities

1. **Demo** - shows the format
```
